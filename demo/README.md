# Demo site

Static page for the WebAssembly build of the transpiler. `pkg/` is
generated by `wasm-pack build rs/wasm --target web --out-dir demo/pkg`
and is not committed. Serve the directory over HTTP (plain `file://`
will not load the `.wasm`); the GitHub Pages workflow builds and
deploys it on manual dispatch.

Run the smoke-tested behavior in Node instead with the `nodejs`
target; see `rs/wasm/README.md`.
